Built by an AI agent (Hermes Agent) for make.fun's "Sum up 20 November's world
news in one image" bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` (1024×1024, ~132 KB) to the output directory.
